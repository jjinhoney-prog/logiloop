# 홈 전환 측정

현재 버전: `focused-home-v1`. 별도 분석 업체로 전송하지 않고 서버의 표준 출력에 JSON 이벤트를 기록한다. 저장·검색·보관 기간은 배포 환경의 로그 설정을 따른다. 장기 비교를 위해 운영 로그를 기간별 JSONL로 내보내 보관해야 한다. 사이트 내 통계 대시보드는 포함하지 않는다.

## 집계 기준

- 방문: 같은 탭에서 처음 홈에 진입한 시점부터 30분간의 임시 방문 ID. 사람 수가 아닌 **측정 가능한 홈 방문 수**다.
- 클릭률: 비교 요청 버튼을 누른 고유 방문 ID / 홈 방문 ID.
- 최종 접수율: 실제 접수에 성공한 고유 방문 ID / 홈 방문 ID. 버튼 클릭률보다 이 지표를 우선 비교한다.
- `home_visit`: 홈 진입. 새로고침·뒤로 가기는 동일 ID로 중복 제거한다.
- `request_click`: 홈에서 신청으로 이동. hero/situation/bottom/navigation 위치를 기록한다.
- `request_started`: 신청의 첫 단계에서 기본 조건 입력으로 진행.
- `request_submitted`: 접수 API가 DB 저장 또는 담당자 메일 전달 성공을 확인한 뒤 서버에서 기록. 봇 허니팟·실패·단순 준비서 확인은 제외한다. 파트너 신청도 제외한다.
- 접수 이벤트가 홈 방문 로그와 연결되지 않으면 홈 전환율에 포함하지 않는다. 홈 방문 이전 기간의 ID가 섞이지 않도록 방문 시각 기준으로 비교한다.

연락처·회사명·입력값·쿼리스트링·IP는 이벤트 필드에 기록하지 않는다. sessionStorage 차단, DNT/GPC 사용, 전송 실패, 30분 초과 방문, 다른 탭/기기의 전환은 연결되지 않을 수 있다. 광고 차단·봇·로그 유실에 따른 오차가 있어 전체 방문자/전체 접수와 같다고 해석하지 않는다. 테스트·미리보기 운영 로그도 섞일 수 있으므로 실제 서비스 배포의 로그만 내보내야 한다.

## 실행

Node 22 이상에서 실행한다. JSONL의 각 행은 이벤트 JSON 또는 `{"message":"이벤트 JSON 문자열"}` 형식이다. 다른 로그는 무시한다. environment가 production이고 현재 버전인 이벤트만 집계한다.

```sh
node --experimental-strip-types scripts/report-funnel.mts /path/to/runtime-logs.jsonl
node --experimental-strip-types scripts/report-funnel.mts /path/to/runtime-logs.jsonl 2026-10-12T00:00:00+09:00 2026-10-19T00:00:00+09:00
```

기간 끝의 방문까지 접수 기록을 포함하도록 종료 시점 이후 최소 30분의 로그도 함께 내보낸다. 집계는 방문 시각을 기준으로 한다. 방문 0건의 비율은 null(계산 불가)이며 0%로 표시하지 않는다. 이전 화면에는 측정 코드가 없으므로 과거 전환율을 추정하지 않는다. 이번 버전부터 기준선을 확보한다.
